## 已呈现的设计

### 首页

- 用用户提供的满月、少女、云霞与水面倒影插画构成主要视觉。
- 桌面：左侧品牌介绍、主要操作与接入说明，右侧大幅插画；用渐隐处理图片左边缘和底部。
- 保留参考稿“连接模型，让灵感启程”的标题、宋体标题气质、暖白主按钮和较小圆角。
- 首页说明银月是模型 API 中转站，展示模型价格、接入与用量管理入口；无未经验证的稳定性、低价或延迟数字。
- 后续内容依次为服务说明、三个使用方向、浅色接入步骤、结束行动区。
- 手机：原图完整主体在上，文案在下，菜单收进可展开导航；不把桌面左右布局直接缩小。

### 控制台

- 共享原图作为天空背景，顶部保留明显月亮与云层。
- 左侧导航、欢迎区、余额/今日用量/今日请求、快捷入口、公告、最近使用记录组成概览。
- 数据面板使用深蓝半透明底色、细边线与有限圆角，使插画可见且数据有独立阅读面。
- 手机保留顶部菜单；余额占一行，其余两个数字并排；快捷入口排列为四项；记录保留模型、状态和金额。
- 所有账户金额、模型调用、用户名与公告都是演示内容。按钮只切换预览或展示说明，不创建密钥、订单或真实调用。
- 预览顶部的“首页设计 / 控制台设计”切换条不属于正式网站。

## 正式开发时如何落实

这部分是实施计划，不是已完成事项。开始修改业务前重读根 AGENTS.md、web/AGENTS.md，以及 shadcn-ui、React 和涉及文本的 i18n 技能；本次不修改认证、计费、数据库或上游代理逻辑。

1. 核对生产实际使用默认首页还是后台自定义首页，避免修改不生效或同时出现两套入口。
2. 准备项目内的图片资源、手机/桌面尺寸和裁切策略。品牌大图与导航小图标分别处理，先验证小尺寸可辨认性。
3. 在 `web/src/styles/theme-presets.css` 及现有主题配置中定义银月色彩、边线与表面层次；保留主题偏好与深浅模式能力。
4. 首页从 `web/src/features/home/` 的现有 Hero、内容分区与 PublicLayout 接入；从统一品牌配置读取名称和图标。
5. 控制台从 `web/src/components/layout/components/` 的 AppHeader、AppSidebar、AuthenticatedLayout、SectionPageLayout 接入，复用已有导航与移动抽屉，不复制设计稿里的手写交互。
6. 概览页在 `web/src/features/dashboard/components/overview/` 中使用真实查询、账户数据、已有金额格式化与业务组件。设计稿里的金额和模型名不能硬编码进产品。
7. 按顺序覆盖密钥、钱包、使用记录、模型价格、个人设置，再检查弹窗、提示、空状态、错误和加载状态；数据密集页面需提高内容底面的不透明度。
8. 登录注册仅在用户批准该阶段范围后处理视觉；若修改认证相关文件或交互，执行项目要求的 OWASP 阅读与回归流程。
9. 新增面向用户的文案需完成全部七种前端语言。显示真实价格时复用现有展示与单位，不改变计费语义。
10. 使用项目 `.dev/run` 完成相关检查，依据实际脚本执行 typecheck、受影响测试、lint 和前端构建；这与发布镜像、部署线上是分开的任务。

## 移动端验收清单

- 320/360/390/430 像素宽度，整页无意外横向滚动。
- 首屏图像主体、标题、主要操作之间不重叠；窄屏可正常换行。
- 菜单可触摸操作和键盘关闭；正式产品还需验证焦点、抽屉、滚动锁定与返回行为。
- 密钥和模型长名称、金额、日志、复制与操作入口保持完整；表格溢出局限于容器内。
- 输入框与表单按钮不被软键盘遮挡；处理底部安全区、横竖屏与浏览器工具栏变化。
- 有效触摸目标约 44px；关键信息不依赖悬停；真实产品正文满足 WCAG AA 对比度。
- 尊重减少动画偏好，手机避免大面积实时模糊和持续动效。

## 已完成与未完成的验证

已完成：冻结前用 Chromium 检查首页与控制台在 320/360/390/430 宽度无整页横向溢出；菜单打开和 Escape 关闭、预览消息及页面切换正常，无脚本运行错误。归档后的离线验证结果另见 manifest.json。

未完成：真实 API 接入、真实手机 Safari/Android 浏览器、软键盘与安全区、账户权限、认证和支付流程、生产构建、全站无障碍验收、正式部署。本设计稿不能作为上述功能已通过的证据。

## 待评估问题

- 大面积夜空蓝与连续深色面板显得厚重，尤其在白天手机使用和长时间阅读时。
- 首页的品牌氛围已经建立，但选模型、看实际价格、判断可用性和快速接入的决策信息还不够靠前。
- 这些问题保留在 V1.0，后续在独立 V1.1 中比较；不通过覆盖本版来“修正历史”。
