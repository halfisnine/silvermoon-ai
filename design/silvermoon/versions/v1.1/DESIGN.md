# V1.1 · 暮色与清晰接入（预览 1）

日期：2026-11-16（Asia/Shanghai）。状态：独立可交互设计预览已完成，等待用户评价；不是生产前端实现，也不代表已上线。

前一版：`../v1.0/`，已冻结，未作修改。本版的本地保存标记为 `design/silvermoon-v1.1-preview.1`。

## 用户目标

用户认可 V1.0 的插画方向，但提出：首页需要对大模型中转站用户更有吸引力，整体暗色可能过重。用户授权制作下一版供查看，并要求保留各版本与实施说明。

## 相对 V1.0 的变化

- 首页保留原始月亮、人物、云霞与倒影；标题改为“把你需要的模型，接入日常工具。”，明确服务用途。
- “查看模型与价格”为首要操作，辅以“注册并接入”和接入指南。点击模型入口在当前页定位模型区域。
- 首屏之后使用月白、浅蓝紫与暮霞色，增加模型系列展示、用途筛选、搜索、无结果与清除筛选。
- 接入部分解释协议匹配、模型选择、密钥与地址；帮助部分回答工具接入、费用记录与调用排查。
- 模型、价格和使用状态不作虚假承诺：三个系列是排版示例，未表示实际供应；不填写虚构的模型价格、可用率、延迟或折扣。
- 控制台保留 V1.0 的原图、数据量、余额、请求次数、两条使用记录、快捷入口与公告。面板改为月白与淡粉，文字改为深蓝；侧栏和顶部栏同步提亮。
- 手机单独安排图文顺序，保留顶部完整导航；余额占一行，次级数据并排，辅助文字做小屏调整。
- 预览工具栏提供首页/控制台切换以及相同页面的 V1.0 对照链接，不属于正式产品界面。

## 文件与资源

- `index.html`：预览入口。`styles.css`、`preview.js`：设计稿样式与演示交互。
- `source.html`：归档时入口的相同副本，依赖相同的本地样式与脚本。完整源文件以 manifest.json 为准。
- `assets/moonlight.webp`：从 V1.0 复制的原始插画，内容一致。
- `assets/fonts.css` 与字体文件：为本版正文、表单标签与弹窗文字生成的 Noto Sans SC / Noto Serif SC 本地字符子集，附 OFL 许可证。不能用于未知的真实用户内容或完整多语言产品。
- `screenshots/`：1440px 桌面首页/完整首页/控制台、390px 手机首页/控制台和并排稿。
- `__tests__/preview.cjs`：设计稿的浏览器交互与布局回归检查。
- `verification.json`：实际运行的验证结果。
- `SHA256SUMS`：本次快照文件校验清单。

## 本版可体验的交互

1. 首页和控制台切换，对照链接跟随当前页面。
2. 首页模型入口和接入/帮助链接在正确页面定位对应区块。
3. 模型用途与搜索同时生效，忽略英文大小写，零结果可一键清除。
4. 模型详情、计费说明、接入清单与账户操作使用本地演示弹窗。
5. 弹窗具有可访问名称，支持 Escape 关闭、关闭按钮和关闭后的焦点返回。
6. 手机导航展开、Escape 关闭以及菜单点击后的页面切换。

支付、注册、密钥、账户和模型调用都不会发生真实操作；示例与无实时数据的限制在对应位置说明。

## 正式前端的实施方式

本版沿用 V1.0/DESIGN.md 的复用和安全要求，以下为新增差异：

1. 品牌配色应进入现有主题变量，分开处理夜景展示区、浅色工作区和语义状态；不要将这一版直接强制为所有用户的偏好。
2. 首页模型展示必须取实际可展示的模型和价格数据，保留已有访问权限，不将设计稿的三个系列硬编码为可用供应。
3. 价格详情复用已有模型价格页、字段、计价单位、分组规则与格式化能力；此设计不改计费表达式或价格配置。
4. 检索已有模型列表、筛选、搜索、空状态与弹窗组件。原生 HTML 演示交互只是视觉原型，不作为生产 React 的复制实现。
5. 控制台在现有公共布局与概览组件中接入浅色面板，复用原有业务数据和格式化。长表格、日志详情和钱包支付步骤要另行适配与验证。
6. 内容页的插画、主题与表面明度应按页面职责控制。浅色面板需保持足够不透明度，避免图片干扰数据。
7. 后续需完成 i18n 七语言、真实 API 状态、触摸/键盘焦点、加载/错误/空数据、认证流程与项目规定的检查；本稿只有中文并且只演示静态数据。

## 已运行验证

执行命令：

```sh
node --check design/silvermoon/versions/v1.1/preview.js
NODE_PATH=/tmp/silvermoon-visual-check/node_modules node design/silvermoon/versions/v1.1/__tests__/preview.cjs
```

依赖为本次临时预览工具中的 Playwright 与 `@sparticuz/chromium`，未加入产品依赖。其他环境可在独立工具目录提供同名依赖；也可用 `SILVERMOON_BROWSER_EXECUTABLE` 指定 Chromium。

结果：

- 离线浏览器中图片、字体、样式与脚本正常加载，无外部网络请求与脚本错误。
- 首页与控制台在 320、360、390、430、768、1024、1440px 均无整页横向溢出，共 14 组布局检查。
- 用途筛选、大小写不敏感搜索、组合过滤、空结果、清除筛选通过。
- 锚点定位、版本对照地址、手机菜单及 Escape 通过。
- 320 × 640 弹窗处于视口内；Escape 关闭并恢复触发按钮焦点。
- 充值示例只显示说明，不发起付款。
- 实际查看桌面与手机截图，修正了文字与明亮月亮的对比，以及字体子集缺少占位文案的问题。
