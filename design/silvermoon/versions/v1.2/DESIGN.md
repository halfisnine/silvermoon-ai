# V1.2 · 月下直达（预览 1）

日期：2026-11-16。状态：独立可交互视觉预览，等待用户评价。不是生产前端，没有上线。

前一版为 V1.1 预览 1；V1.0、V1.1 均保持冻结。本版使用独立目录和本地标记 `design/silvermoon-v1.2-preview.1`，未推送远端。

## 设计依据

用户认可 V1.1 首页视觉，但指出内容过多、核心不突出，控制台缺少银月气质。对八个同行首页的观察见 `../../research/2026-11-16-homepage-comparison.md`。本版按用户授权进一步修改，不把同行宣传数字当作银月服务承诺。

## 本版变化

- 首页收为插画首屏、接入与支持卡、单条公告及页尾。主操作是进入控制台、模型与价格。
- 保留原图的月亮、人物、云霞与倒影，标题使用“连接模型，让灵感启程”，用一行说明交代大模型 API 用途。
- 完整模型示例、搜索、筛选及空结果处理移到单独的 `#models` 预览页面；首页不再铺陈模型系列、工具介绍、FAQ 和重复行动区。
- 接口复制、售后、社群入口直接可见。接口使用保留的 `.example` 域名，并标注示例和不可调用；客服与群号尚未确认，点击显示说明，没有假号码或外部跳转。
- 公告采用可点击摘要，不自动弹出。接入清单与帮助沿用上一版演示弹窗。
- 控制台增加独立月夜欢迎横幅，侧栏采用暮蓝到灰紫的渐变；数据卡使用月白、浅紫、晚霞粉和细色边。数据面板保留足够不透明度。
- 控制台保留原来的示例余额、费用、请求数及两条记录，增加接口地址入口和常用导航。手机显示公告卡，不再直接隐藏。
- 手机首页缩短插画区域，390 × 844 下两个主操作均在首屏内；长地址允许换行。控制台余额占整行，其余两项并排，快捷入口不横向挤出页面。

## 交互与边界

可体验首页、模型页面、控制台切换，浏览器后退，筛选与搜索，手机菜单，公告/帮助弹窗，地址复制及失败提示。弹窗支持 Escape 和关闭后的焦点返回。页顶工具栏用于设计对比，不属于正式产品界面。

模型列表和控制台均为示例。没有真实价格、服务状态、折扣、支付、注册、密钥创建或模型调用。模型页面从 V1.1 延续，用于证明首页的入口有合理去向，不是本轮完整价格页设计。

## 文件

- `index.html`、`styles.css`、`preview.js`：独立设计预览，支持本地静态服务及离线文件浏览。
- `source.html`：冻结时入口副本；需要和其余资源一起保存。
- `assets/`：原始插画及本地字体与许可证。字体是 Noto Sans SC 400/500、Noto Serif SC 400 的当前文案子集，不适用于真实动态用户内容。
- `screenshots/`：桌面、手机首页与控制台的首屏及完整页面。
- `__tests__/preview.cjs`、`verification.json`：实际浏览器验证脚本与结果。
- `manifest.json`、`SHA256SUMS`：版本信息及文件校验。

## 正式开发的接入方式

本次是独立静态设计档案，没有修改 `web/` 或后端代码，也不新增产品组件和翻译键。正式移植时：

1. 在现有公共布局、首页和控制台概览上使用品牌主题变量；保留登录态、权限与原有路由。
2. 复制行为复用 `web/src/components/copy-button.tsx` 和 `use-copy-to-clipboard`；已检查控制台 `features/dashboard/components/overview/api-info-item.tsx` 的实际调用。现有 CopyButton 支持文案、尺寸、变体和提示，无需新增替代组件。
3. 弹窗复用 `web/src/components/dialog.tsx`。预览中的原生 dialog 和剪贴板实现只供无需产品构建的离线稿使用，不作为生产替代实现。
4. 模型入口进入现有模型价格页；接口来自确认后的站点配置，联系方式与公告来自真实运营配置。不得把 `.example` 域名或当前样例数据直接上线。
5. 复用现有格式化、数据查询和业务状态；不改计费规则。新增产品文案按 i18n 技能通过脚本加入七语言，再执行同步与检查。本轮中文设计稿不代表多语言产品已完成。
6. 首页艺术区与操作区分别控制色彩，控制台用不透明浅色面板保证阅读；避免将装饰图片铺进每个表格单元格。

## 验证

执行：

```sh
node --check design/silvermoon/versions/v1.2/preview.js
NODE_PATH=/tmp/silvermoon-visual-check/node_modules node design/silvermoon/versions/v1.2/__tests__/preview.cjs
```

浏览器检查覆盖 320、360、390、430、768、1024、1440px 三种页面，共 21 组无整页横向溢出；离线图片和字体加载，无外部请求及脚本异常；模型筛选、搜索、空结果与重置；页面切换与浏览器后退；320 × 640 弹窗边界、Escape 和焦点恢复；手机菜单与公告；复制成功与权限拒绝反馈（剪贴板边界模拟）；支付操作仅显示说明；对照链接随当前页面变化。

查看了桌面和手机实际截图，并修正首页插画溢出、手机副标题与图片重叠、复制符号缺字。截图在临时反馈消失后保存。

尚未验证真实 Safari / Android 设备、完整无障碍对比度、多语言动态内容及真实账户业务；生产前端构建不在本轮静态预览范围内。
