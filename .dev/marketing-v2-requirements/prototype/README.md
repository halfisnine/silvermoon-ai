## 打开

- 开发机静态预览：`http://127.0.0.1:43889/`。远程访问需通过 Codex 预览或已有端口转发。
- `standalone.html` 是可下载后直接双击打开的完整单文件版，无网络、登录、依赖安装要求。
- `index.html`、`style.css`、`experience.js`、`app.js` 为原型源文件，放同一目录也可直接打开。
- 独立启动：在仓库根执行 `python3 -m http.server 43889 --bind 127.0.0.1 --directory .dev/marketing-v2-requirements/prototype`，若端口已使用不要重复启动或停止别的服务。

原型只使用固定样例和本次页面内存。不会调用业务、支付或管理接口；刷新重置。不同页面的金额是独立展示样例，不是同步运行的模拟账本。局部签到、补签、兑换和抽奖操作提供即时反馈，不代表已经实现持久化或财务结算。

## 页面与核对路径

共 21 个审阅导航入口，“我的奖励”内含两个视图。左侧导航是审阅目录，不等于正式产品新增 20 个菜单。

1. 管理员：活动列表、注册、签到、充值、邀请、奖池列表、奖池编辑、奖励记录及详情、付费兑换码、现有用户管理的禁用操作。
2. 用户：钱包与充值、个人资料签到与补签、抽奖及机会/结果、邀请、使用日志及来源详情、我的奖励（奖励记录／赠金明细）。
3. 审阅辅助：总览、状态与中英文样例、需求覆盖与 N01–N04 待定项、N05 已确认项。

建议核对：

- 签到配置 → 个人资料：每日与连续额外奖励叠加；补签按漏签日核资格、次数按活动累计。
- 充值配置：切换三类条件和频率；单笔可比例，累计不允许比例；累计机会支持直接／概率赠送，独立选择奖池。
- 奖池配置：多奖项、赠金组合、有限/不限库存、允许未中奖；未决预算/轮次明确标注。
- 兑换码 → 钱包：实付人民币与到账付费金额分别记录，卡密是付费充值。
- 钱包 → 赠金明细 → 使用日志详情：不拆两条调用，来源与失效金额可解释。

当前版推荐核对：奖池配置 → 选择展示方式、编辑组合奖品 → 用户效果预览 → 抽奖页切换样例数量、指定演示结果 → 点击 GO 或单个礼盒。再到个人资料切换活动阶段，验证签到与补签。样例数量与结果选择是审阅工具，正式用户页不显示；未中奖场景临时加入空奖，不修改保存的配置。不同样例共享本次浏览的 3 次演示机会，可单独重置。切页时已形成的演示结果保留，取消未结束的视觉动画。

## 范围和复用边界

这是 `.dev/` 下的独立设计审阅材料，不进入 `web/` 路由、构建、翻译文件或业务接口。已查阅主分支个人资料签到结构，以及项目 ConfirmDialog、DataTable、Input 等组件。它们依赖应用 React/Base UI/TanStack 运行环境；本稿要求可单文件离线打开，不装载应用，因此用文档级 HTML 控件模拟交互。正式实施仍必须复用主分支共享组件，不将此原型当组件实现搬入产品。

中文用于本轮业务核对；中英文样例只演示关键术语和布局，未声称完成全站翻译。正式实现必须完整支持现有语言。顶部主题切换是原型壳层的三组配色样例；P1.3 抽奖区域固定采用参考稿样式，不跟随该切换。主题包开发规范、ZIP 上传与入库继续延期。

全部金额使用元，人可见表单和记录不暴露内部数值；实付人民币单独标明。金额、日期、门槛、库存和概率仅为示例。未知业务不能通过原型默认值变成批准规则。

原型未实现多实例、并发、计费、支付、真实发奖、数据库迁移、现金退款或鉴权。N01–N05 仍见上级 `05-open-decisions.md`，不因为页面存在就视作定稿。
