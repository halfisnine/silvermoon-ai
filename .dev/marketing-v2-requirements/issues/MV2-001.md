# MV2-001：充值资格与活动时间规则

状态：开发完成（独立整项验收通过）

依赖：无

依据：00–07 当前需求及08技术方案。不得从旧MR验收移植产品行为。

## 验收项（评审后冻结）

- [ ] **A01** 五种充值玩法精确对应02：全站首笔、首次单笔、每笔、首次累计、循环累计；资格事件按本站成功入账事实，门槛只看实付人民币。
- [ ] **A02** 累计30+70满100一档，后250两档余50；首次累计只一次；非首次订单不能补成全站首充；负数/零事件/无效门槛及溢出拒绝，无浮点金额运算。
- [ ] **A03** 状态计算覆盖开始时刻、结束时刻、长期活动、未发布隐藏、结束72小时前1秒与恰满72小时；展示隐藏不修改任何资产或领取事实。
- [ ] **A04** 资格按已入账事实发生时间判断，不使用处理时间；开始含、结束不含、暂停区间开始含结束不含，暂停前事实延迟处理不丢资格，暂停中事实事后不补成资格。展示是否公开与已生效事实的判断分开；五玩法测试包含未达标、首次失败后后续达标、两单合档与跨多档，返回新增档数和新余数可核对。
- [ ] **A05** 纯规则不含数据库、缓存或HTTP，不依赖旧营销包；不宣称已实现持久防重或后台接口。测试覆盖结果与边界，不测试文件布局。
