# MV2-006：独立奖池机会库存与开奖

状态：开发完成

依据：00–07 当前需求及08技术方案。不得从旧MR验收移植产品行为。

## 验收项（评审后冻结）

- [ ] **A01** 转盘/盲盒同权重算法、库存耗尽退出实际抽取，组合奖为一份奖项；空奖是正常结果，不将技术失败冒充未中。
- [ ] **A02** 全站名额计入已发未用和确认待发责任；无支付预留；追加按供给核对并留痕，不能用空奖概率放大保证容量。
- [ ] **A03** 一次机会一次持久结果，重复开奖回原结果，结果提交/发奖中断可恢复；最后库存/名额/追加并发两个实例不超发，三库验证。
- [ ] **A04** 单项机会不足不拆发，历史名额不足不自动补、空奖/过期/清零不自动恢复发行名额；允许不限量奖项但发行总名额有限。开始后核心规则复制新池，允许补原库存/追加；不缩短旧截止、仅延期有效机会、暂停自然计时不扣机会，技术失败已承诺任务恢复。
- [ ] **A05** 按用户归属与稳定来源键校验，服务端随机决定结果且概率不由浏览器控制；奖励到账证据真实。此Issue先实现持久奖池服务，活动引擎在007接入，不能用桩替代机会与奖品事务；管理/用户HTTP接口在对应后续Issue集成。

- [ ] **A06** 组合奖跨步骤发放必须保存整份责任并可恢复，部分到账不能显示全部成功；后台管理/追加与用户开奖写入口的鉴权由012/013整体接入验收，核心服务不自行绕过调用者归属。

- [ ] **A07** 有限/不限量奖项混合时只将正权重可兑付奖项计供给，空奖不计；3次奖励只余2次整项不发，既有未用/待发责任不能重复追加。即使尚未开始也不能改坏已承诺供给/旧截止；延期与抽奖/到期/清零并发，恰到期不复活，暂停自然到期。
