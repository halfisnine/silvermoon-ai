# MV2-010：签到连续奖励与活动内补签

状态：开发完成

依赖：007,008

依据：00–07 当前需求及08技术方案。不得从旧MR验收移植产品行为。

## 验收项（评审后冻结）

- [ ] **A01** 无需充值/当天实付/前一天实付三条件，上海日历，旧签到不并行发奖，点击一次判断所有适用活动及互斥。
- [ ] **A02** 每日与连续额外叠加，活动起算，一次/周期循环、断签重计；7天样例第7天3元，七天共9元。
- [ ] **A03** 补签目标日资格、最近N天及活动边界、每人每活动总次数跨月不重置、开关决定补每日；修复连续不得重复已发档位。
- [ ] **A04** 双实例同日签到/同日补签/签到补签交叉不会双发或超次数；三库和日界线、结束场景验证。

- [ ] **A05** 复制活动/改名不得把原活动漏签或旧奖励事实重放到新活动；补签仍按目标日原活动和原资格，原活动已领连续档位不可重复。
