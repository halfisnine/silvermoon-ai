# MV2-009：注册有礼与邀请奖励统一

状态：开发完成

依赖：007,008

依据：00–07 当前需求及08技术方案。不得从旧MR验收移植产品行为。

## 验收项（评审后冻结）

- [ ] **A01** 各实际注册入口含OAuth等均从成功事实触发，注册赠金和邀请赠金分受益人；旧QuotaForNewUser/Invitee/Inviter及AffQuota转付费不再双发混入本金。
- [ ] **A02** 邀请支持注册、每好友累计一次/循环、好友实付比例，活动前关系不参加、好友分别累计、仅活动内入账；不开放注册后补绑。
- [ ] **A03** 同一邀请关系和事实重试、多实例处理只发一次；赠金入账独立，首充记录不能因退款清零重置。
- [ ] **A04** 读适用OWASP资料、保留认证安全，相关注册/权限失败回归；三库及恢复验证。
