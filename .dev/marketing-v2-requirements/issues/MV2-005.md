# MV2-005：Realtime轮次资格累计费用及止损

状态：开发完成

依赖：004

依据：00–07 当前需求及08技术方案。不得从旧MR验收移植产品行为。

## 验收项（评审后冻结）

- [ ] **A01** 核对主分支协议的音频输入/响应/自动回复证据，覆盖持续输入、打断、回复重复、关闭；不是一个音频片段就一轮。
- [ ] **A02** 每轮重新判断有效赠金，旧轮可结算；缺可靠起点的自动回复按首次收到开始通知，不继承旧连接资格。
- [ ] **A03** 保持累计计价与舍入，多扣按最近实际消费原来源冲正；赠金0.10+费用0.15时付费承担0.05，实际用量不因费用下降减少。
- [ ] **A04** 所有资金不足时在可执行边界停止现有连接继续产费并阻止新轮，保留未结真实费用；多连接/双实例不能重复消费；延迟费用如实记录不自动免账。
- [ ] **A05** 至少用协议夹具和真实双进程账本验证轮次跨到期、闲置回复、并发、断连/重试/恢复，未核实协议边界不得标通过。

- [ ] **A06** 断连且缺最终用量不能视为零费用自动释放；后续真实响应与旧轮关联，不能把前段欠费转扣给新轮；未结阻止清退，核对仅根据可信原始证据。
