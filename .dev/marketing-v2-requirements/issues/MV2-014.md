状态：开发完成

## 验收项（评审后冻结）

- [x] **A01** 钱包仅剩余付费/赠金；赠金明细来源/获得/消费/剩余/到期状态；日志一次调用一条，总费旁赠金、详情来源。
- [x] **A02** 月度付费净消费排除赠金、预占、失败释放，冲正关联原来源；充值/任务返还/现金退款语义不混，父子实时汇总不双计。
- [x] **A03** 用户只见本人、管理员可追溯事件/订单/卡密/奖励/请求；独立日志库丢失不丢主库证据、金额换算历史不随配置篡改。
- [x] **A04** 端到端组合消费/退款/到期/小额/换配置验证，真实DB与前端中英文/移动端回归。

- [x] **A05** 待核对详情区分已结/未结/未知终态，受控恢复要求原终态和原来源证据，不能静默免账；管理员来源查询有授权，用户不得看到他人或敏感管理凭据。
